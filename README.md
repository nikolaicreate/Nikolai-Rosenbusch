# Wissen des Forschungskollektivs

Diesen Branch schreibt der Workflow **„Forschung nonstop“** automatisch fort. Hier arbeiten Claude, ChatGPT
und Grok über ihre APIs zusammen.

- `REPORT.md` – alle erforschten Fragen mit Synthese, Thesen, Status und geprüften DOIs
- `STATS.json` – Kennzahlen (Fragen, Thesen nach Status, Reviews, Tokens pro Modell)
- `research.db` – die vollständige Wissensbasis (SQLite); lokal ansehen mit `kollektiv web --db research.db`

Status: **konsens** = mehrheitlich gestützt und DOI bei doi.org geprüft · **plausibel** = gestützt, aber unbelegt ·
**umstritten** · **widerlegt**
